# シュレディンガーの五目並べ（オンライン対戦版）

## できること
- 部屋を作成し、部屋番号を友達に共有
- 友達は部屋番号を入力して参加
- サーバーが盤面・手番・観測抽選を管理し、両画面を同期
- 既存のCPU対戦／ローカル対戦も同じ画面に残しています

## 公開サーバーに無料で配置する手順（Renderの例）
1. このフォルダ一式をGitHubの新しいリポジトリにアップロードします。
2. Renderにログインし、New + → Web Serviceからそのリポジトリを選びます。
3. `render.yaml` を使うか、設定を次のようにします。
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
4. デプロイ完了後、Renderが発行する `https://....onrender.com` のURLを開きます。
5. 片方が「部屋を作る」を押し、表示された部屋番号を友達に送り、友達は同じURLで「部屋番号で参加」を押します。

## ローカル起動
Node.js 18以降をインストールしたあと、このフォルダで:
```bash
npm install
npm start
```
ブラウザで `http://localhost:3000` を開きます。

## 注意
- Renderの無料プランは一定時間アクセスがないとスリープすることがあります。
- 現在の部屋データはサーバーのメモリ上にあり、サーバー再起動で対戦部屋は消えます。
- 部屋番号は一時的な対戦用です。アカウントや永続戦績はありません。
